  می‌توانید مطمئن شوید.

## دستورهای دقیق برای شما روی Ubuntu (با اینترنت)
```bash
# ۱) آماده‌سازی
cd modasr-ecosystem
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env   # OPENROUTER_API_KEY, BOT_TOKEN, BALE_BOT_TOKEN را پر کنید

# ۲) تست‌های واحد (باید ۶۳/۶۳ PASS بدهد، دقیقاً مثل اینجا)
python3 -m unittest discover -s tests -p "test_*.py" -v

# ۳) تست‌های زنده (یکی‌یکی، نتیجه‌ی هرکدام را یادداشت کنید)
python3 scripts/test_gemini_live.py
python3 scripts/test_telegram_connection.py
python3 scripts/test_bale_connection.py

# ۴) اگر همه‌ی بالا سبز بود، اجرای واقعی (هرکدام در یک ترمینال/سرویس جدا):
python3 apps/telegram-bot/main.py
python3 apps/bale-bot/main.py
```
نتیجه‌ی هرکدام (خصوصاً مرحله‌ی ۳ و ۴) را برایم بفرست (بدون چاپ کلید/توکن) تا اگر جایی
واقعاً فرق داشت با فرض مستندشده (خصوصاً فرمت پاسخ بله)، اصلاحش کنم.
